# Ejemplo GIT

Repo para prueba de GIT en el contexto de POO 2026

Este repo contiene 1 archivo por estudiante. El nombre del archivo tiene el patron

- Ultimos 3 digitos de legajo
- Inicial del primer apellido

El contenido de cada archivo es una breve encuesta que deben responder.

# Secuencia de trabajo

Guiados por los docentes, realizar la siguiente tarea

- Ingresar al repositorio [Github](https://github.com/poounlu/ejemplo-git-2026)
- Hacer Fork del repositorio original en la plataforma elegida
- Crear una working copy con Intellij IDEA
- Buscar su archivo y responder la breve encuesta con si
- Hacer commit + push
- Crear un Pull Request indicando brevemente el cambio sugerido
